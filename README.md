# PROJECT: STAR-SPHERE SHOOTER
## Technical Specification v1.1 (Final) | Web Application (Vanilla JS)

### 1. プロジェクト概要
宇宙空間を舞台にした360度全方位型シューティングゲーム。プレイヤーは固定された位置から、周囲に出現するターゲットを制限時間20秒以内にどれだけ多く破壊できるかを競う。フレームワークを使わず、Vanilla JSとThree.jsを用いることで、軽量かつ高速な描画(60fps)を実現する。

### 2. 機能要件 (Functional Requirements)

#### コア機能 (Must Have)
- **3D描画エンジン**: Three.jsによる宇宙空間の構築 (背景: Starfield)。
- **視点制御 (PC)**: MouseMoveによるエイム操作、およびWASDキーによるカメラの補助回転。
- **視点制御 (スマホ)**: スワイプによるエイム操作、およびジャイロセンサー (`DeviceOrientationEvent`) を用いた直感的なVR風視点移動。
- **ポインターロック (PC)**: ブラウザ上でマウスカーソルを隠し、操作性をFPSに最適化。
- **射撃操作**: PCはマウスクリック、スマホは画面下部に配置された専用の「SHOOT」ボタンによるタップ操作。
- **ターゲット管理**: 常時 **50個** を維持。1個破壊されるとランダムな座標に即座に1個補充。
- **動的ターゲット**: ターゲットは静止しておらず、極座標上でランダムな角速度 (`dPhi`, `dTheta`) を持って常に移動し続ける。
- **タイマー**: 20秒のカウントダウン。0秒で操作不能となりリザルトへ。
- **リザルト**: 最終スコア表示とリプレイ機能。
- **リーダーボード**: セッションローカルでのハイスコアランキング表示 (プレイ開始時刻とスコアをTOP 3まで記録・表示)。

#### 拡張機能 (Nice to Have - 今後の展望)
- Google/GitHubログイン等のアカウント連携およびスコア永続化。
- BGM/SE (宇宙空間をイメージしたシンセサウンド、レーザー射撃音の追加)。

### 3. 非機能要件 (Non-functional Requirements)
- **パフォーマンス**: ターゲット数50個、かつ全ターゲットが動的移動している状態でも常時60fpsを維持。
- **レスポンシブ**: PC (マウス＆キーボード) と スマホ (スワイプ＆ジャイロ＆タップ) の両デバイスに完全対応するUIデザイン。
- **データ整合性**: クライアント側での単純な変数書き換えによるスコア改ざんを防止するためのチェックロジック (JavaScriptのPrivate Class Fields `#` を用いたカプセル化)。
- **インフラ**: Google Cloud Runによるコンテナホスティング (Node.js/Expressによる軽量な静的ファイル配信)。

### 4. ターゲット生成・移動ロジック
ターゲットはプレイヤー(原点)を中心とした半径 $r$ の球体表面上に配置される。生成時およびフレーム更新時に極座標系を用い、直交座標系 $(x, y, z)$ に変換する。

$$ x = r \cdot \sin(\phi) \cdot \cos(\theta) $$
$$ y = r \cdot \sin(\phi) \cdot \sin(\theta) $$
$$ z = r \cdot \cos(\phi) $$

※ $\theta$ (方位角) は $0$ から $2\pi$、$\phi$ (仰角) は $0$ から $\pi$ の範囲。
※ さらに各ターゲットにランダムな角速度 (`dPhi`, `dTheta`) を持たせ、毎フレーム座標を更新して回避行動（オービタルムーブメント）を表現する。

### 5. テストケース (Test Cases)

| ID | テスト項目 | 期待される結果 |
|---|---|---|
| TC-01 | ターゲット補充 | 1個撃破直後、即座に別の場所に1個出現し、総数50が保たれる。 |
| TC-02 | 360度エイム(PC) | マウス移動に合わせて、全方位(上下含む)に死角なく視点が動く。 |
| TC-03 | タイムアップ | 20.0sから0.0sになった瞬間に射撃が無効化され、リザルト画面が出る。 |
| TC-04 | リプレイ | リプレイボタン押下で、タイマーとスコアがリセットされゲームが再開する。 |
| TC-05 | ジャイロエイム(スマホ) | 縦持ち状態でスマホを左右・上下に傾けると、現実の動きに追従して視点が正しく移動する。 |
| TC-06 | リーダーボード | ゲーム終了時、過去のスコアと比較され、TOP3に入っていれば正しくランキングに反映される。 |
